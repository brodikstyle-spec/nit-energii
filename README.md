# Нить энергии

Интерактивный тренажёр построения и защиты электрической сети.

Опоры ЛЭП устанавливаются на белые кружки, трансформаторы — на электростанцию и подстанции. Исправная цепь зажигает окна у потребителей. Зелёные карточки показывают защиту, красные — нештатные ситуации. При наведении на объект можно рассмотреть установленные карточки.

Статическая версия для GitHub Pages. Все файлы находятся в корне; отдельный сервер для игровой логики не требуется.
